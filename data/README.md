# data/

`northeuralex_sel.csv` — 31 languages (lat spa por cat ita fra ron; deu eng nld swe dan nor; rus ukr pol; fin krl ekk liv hun; sme smn sma; tur azj kaz; khk bua xal; eus)
extracted from the Lexibank CLDF release of NorthEuraLex 0.9 (columns Language_ID, Parameter_ID, Form,
Segments), kept here so the cloud runners can run the real-data probes. Dellert, J., Daneyko, T.,
Münch, A. et al. (2020). NorthEuraLex (Version 0.9). *Language Resources and Evaluation*,
https://doi.org/10.1007/s10579-019-09480-6 — CC-BY-4.0. Nothing in it is modified; `masscomp/data.py`
maps the CLTS segments onto the prototype inventory at load time.
